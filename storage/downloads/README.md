Đặt file cài đặt thật vào đây theo đúng tên (không dấu, không khoảng trắng).
Thư mục này nằm ngoài `public/` (giống `src/`) nên không ai tải trực tiếp qua
URL được — mọi lượt tải đều phải đi qua `public/tai-file.php`, nơi kiểm tra
đã đăng nhập trước khi cho tải. Đặt file trong `public/` sẽ bỏ qua hoàn toàn
việc kiểm tra đăng nhập này.
